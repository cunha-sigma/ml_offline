**AI use restriction agreement for the client's parent company projects**

**Effective Date:** \[\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\]

**To:** \[Consultant/Subcontractor Name\]

**From:** Sigma Software, Inc., on behalf of itself and its affiliates (collectively, “Sigma”)

This letter amends your existing agreement(s) with Sigma Software, Inc. and/or any of its affiliates (“Agreement(s)”) by incorporating the following terms, effective from the Effective Date:

1.  **Prohibition on use of non-the client's parent company provided AI systems**

You agree that you will NOT use a non-the client's parent company provided “AI System” as defined below to perform any work, services, or deliverables under the Agreement(s) for our client the client's parent company or its clients, affiliates, and partners, except as specifically approved by Sigma in writing. Such approval must be obtained before you start using any AI System.

2.  **Definition of “AI System”**

“AI System” means artificial intelligence or machine learning model, architecture, or system in connection with the Agreement(s), including, without limitation, any model, architecture, or system that, for a given set of objectives, uses machine and/or human-based data and inputs to (a) perceive real and/or virtual environments, (b) abstract these perceptions into models through analysis in an automated manner (e.g., with machine learning), or manually, or (c) use model inference to formulate options for outcomes.

3.  **Approval process for AI System use**

If you need to use a non-the client's parent company provided AI System for the client's parent company-related work, you must receive written approval from Sigma before using it and comply with all specific terms, conditions, and requirements established by Sigma and the client's parent company for each approved use case.

4.  **Disclosure obligations**

Upon Sigma’s request, you agree to promptly provide a complete list of all AI Systems (both the client's parent company-provided and non-the client's parent company provided) that you are using or plan to use in connection with the client's parent company-related work under.

5.  **Precedence**

In the event of any inconsistency or conflict between the terms of this Agreement and any other agreement between you and Sigma, the terms of this Agreement shall prevail with respect to AI System use for the client's parent company-related work.
